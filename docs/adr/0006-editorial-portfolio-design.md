# 0006: 文章と実画面を中心に制作物を見せる

- 状態: Superseded by [0008](0008-reference-led-layout.md)
- 日付: 2026-10-30

## 背景

英語の装飾見出し、均一なカード、実画面ではないイラストが続き、個人の実績よりもテンプレートの見た目が目立っていた。制作物・仕事・NOC の具体的な内容が自然に読める個人サイトにしたい。

## 決定

- split layout は維持し、左に本人と目次、右に制作物と記録を置く。
- 紙に近い背景、黒茶の本文、控えめな赤茶のアクセントを使う。トップの見出しには明朝体を使い、本文との違いをつける。
- 制作物は罫線と余白で区切った一覧にする。ピックアップした項目を大きく見せ、その他は名前・概要と担当内容を二列で整理する。
- 画像を指定しない作品は文章で見せる。画像は作者が用意した実画面などを任意で追加できる。自動のコンセプトイラストは表示しない。
- 技術は装飾的なバッジではなく文字の一覧にする。英語の飾り見出しを減らし、活動の種類は日本語で示す。
- コピーは実際の制作物と経験に合わせた説明にする。見出しと短い紹介文は `content/profile.md` から編集できる。
- モバイルでは縦に並べ、本文・表・コードが画面幅を超えないようにする。

## 検討した選択肢

- 全項目を同じカードにする: コンポーネントは揃うが、項目の重要度と内容の違いが伝わりにくい。
- すべてにイメージ画像を用意する: 視覚的な面積は増えるが、実画面がない作品で説明用の画像が主役になりやすい。
- 文章を基本として実画面を任意にする: 各実績の内容を中心に見せ、追加時の画像制作も必須にしない。

## 影響とトレードオフ

- 制作物の追加は Markdown だけで完結し、スクリーンショットが用意できた時点で画像を足せる。
- 内容の強弱は `featured` と文章量で決めるため、掲載内容に合わせて編集する必要がある。
- 具体的な事実、出典、担当範囲は維持する。見た目を整えるために実績や数値を補わない。
