# 0004: 出典付きの活動データに、任意の終了日を持たせる

- 状態: Superseded by [0005](0005-markdown-content-management.md)
- 日付: 2026-10-30

## 背景

本人の公開 Scrapbox から、インターン・職歴・NOC・受賞・登壇・チーム制作を取り込む。
既存の `Activity.date` だけでは、数日にわたるイベント、長期の職歴、継続中の仕事を表現しにくい。
また、Scrapbox の作成日・更新日は活動が行われた日とは異なる。

## 決定

- 活動には開始時期を `date`、任意の終了時期を `endDate` として持たせる。
- 年・年月・年月日の精度をそのまま保存する。継続中の終了時期は `"present"` とする。
- UI は一つの活動項目の中に開始・終了を表示し、日付には `time` 要素を使う。終了時期の省略は単発の記録として扱う。
- 根拠は既存の `links` に保持し、プロフィールや複数の活動が参照する Scrapbox URL は `src/content/sources.ts` にまとめる。
- URL はページタイトルをエンコードして生成する。スラッシュを含む日付や空白のあるページ名も、一つのページとして参照できるようにする。
- 公開資料の内容を確認してローカルデータに反映する。描画時の API アクセスや自動同期は導入しない。
- 取り込み範囲と根拠は [出典メモ](../content-sources.md) に記録する。

## 検討した選択肢

- タイトルや説明に期間を書く: 登録は容易だが、日付の意味が表示とデータの間で分散する。
- すべてを年月日の形式に揃える: 並べ替えは容易だが、元の記録にない日付を補うことになる。
- 終了日を任意にして元の精度を維持する: 既存の単発の記録を保ち、期間のある項目だけを拡張できる。
- サイト閲覧時に外部ページを取得する: 更新は自動になるが、表示の可用性が外部 API に依存し、未確認の追記もそのまま公開される。

## 影響とトレードオフ

- 新たな職歴や複数日の参加歴も、活動データの追加だけで掲載できる。
- 日付はページタイトル・本文・活動一覧に書かれた実際の時期から取得する。
- 確認できた担当内容、成果、参加と登壇の区別を保つ。受賞名・順位・会社名は元の記録の範囲で記載する。
- 出典に終了時期がない継続中の記録は、本人が終了時期を更新するまで `present` として表示される。定期的な内容の見直しは必要。
- 表示順はこれまでどおり配列の順番とする。年だけ判明している項目も、日付を推測せず任意の位置に置ける。
