# 0008: 二つの参考サイトをもとに、静かな二段組と一覧を設計する

- 状態: Accepted
- 日付: 2026-10-30
- 置き換える判断: [0006](0006-editorial-portfolio-design.md)

## 背景

目指す雰囲気として、[Carl Barenbrug](https://carlbarenbrug.com/) と [Frank Chimero のアーカイブ](https://frankchimero.com/blog/) が指定された。いずれも文字と余白、個人の情報、内容の一覧を中心にしたサイトである。

## 決定

- Carl Barenbrug の等幅文字、控えめな見出し、メタデータと本文の配置を参考にする。
- Frank Chimero の暗いプロフィール側と明るい本文側、簡潔なタイトル・日付の一覧を参考にする。
- PC では左42%をプロフィールと目次、右58%を内容にする。日本語の説明が読める本文幅を取り、狭い画面では縦に並べる。
- 背景は落ち着いた緑灰と明るい灰白。本文は等幅文字を基本にし、巨大な見出しや装飾的なカードを置かない。
- 制作物は説明と成果物へのリンクを並べる。活動は日付・種類・タイトルで一覧し、ネイティブの `details` で担当内容と出典を開けるようにする。継続中の仕事は初期表示で開く。
- 参考サイト固有の文章・写真・フォントファイル・ブランド表現は移植せず、本人のデータと既存のアイコンを使う。
- 動きがなくても読める HTML を基本にし、キーボード操作、フォーカス表示、本文へのスキップ、モバイルでの折り返しを保つ。

## 検討した選択肢

- 以前の明朝体と紙色を継続する: 読み物としては成立するが、今回指定された等幅文字とアーカイブ中心の印象から離れる。
- 参考サイトの寸法をそのまま使う: 英文と日本語の長さや掲載内容が異なるため、説明が読みにくくなる場合がある。
- 共通する構成を本人の情報量に合わせて解釈する: 見た目の方向を揃えながら、制作物と活動の具体的な内容を保てる。

## 影響とトレードオフ

- 実績をまとめて探しやすくし、詳細は必要な項目から読める。
- 画像がなくても成立するが、文章の説明と出典の整理がサイトの質に直結する。
- 左ペインのリンクと本文は `content/site.md` の同じ設定に従う。
