## 取り込み方針

職歴・インターン・NOC・受賞・登壇・主要な参加歴を活動データに整理し、Janus・共有 ToDo・ハッカソン制作の SNS を制作物に追加した。元の記録にある活動の時期を使い、Scrapbox の作成日・更新日を開催日として扱わない。

会社や役割が書かれていない項目は、確認できた名称と期間を載せる。チームの成果と個人の成果は元の記述に従う。活動のリンクから根拠を参照でき、出典リンクは `content/activities/` と `content/projects/` の各 Markdown の `links` に保存している。

- SmartHR と TwoGate は一覧にある 2025年9月の精度で記載し、具体的な開始日・終了日は補っていない。

- 既存の認証サンプル・タイピングゲーム・食品管理アプリ、既存プロフィール由来の C++・Python・嗜好は引き継いでいる。
