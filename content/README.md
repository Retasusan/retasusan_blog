# ポートフォリオの管理

ここが編集用のフォルダーです。ふだんの更新は、この中の Markdown だけで行えます。

| 編集したい内容 | 開く場所 |
| --- | --- |
| 名前・自己紹介・トップの見出し・アカウント | [profile.md](profile.md) |
| セクションの順番・表示設定 | [site.md](site.md) |
| 制作物を追加・編集 | [projects/](projects/) |
| 仕事・参加・受賞・登壇の記録 | [activities/](activities/) |
| 技術のグループ | [skills/](skills/) |
| 新規作成用のひな形 | [_templates/](_templates/) |

## VS Code で管理する

おすすめ拡張にある **Front Matter CMS** を入れると、制作物・活動・スキルを一覧と入力欄で管理できます。
拡張を使う場合も、保存されるのはこのフォルダーの Markdown です。

拡張なしでも使えます。VS Code の「ターミナル → タスクの実行」から、次のタスクを選んでください。

- `管理: 制作物を追加`
- `管理: 活動・仕事を追加`
- `管理: スキルを追加`
- `管理: 内容を検証`

作成したファイルは `draft: true` の下書きになります。本文を整え、公開するときに `draft: false` に変えます。

## 書き方

`---` で囲まれた先頭部分が設定、その下がページに表示する本文です。

```markdown
---
type: activity
title: "勉強会で発表した"
date: "2026-10"
kind: event
links: []
draft: true
---

発表した内容や、学んだことを書きます。

- **担当したこと**
- 次に試したいこと
```

本文では見出し、太字、リンク、箇条書き、表、チェックリスト、コードブロックが使えます。
VS Code の Markdown プレビューは `Cmd+Shift+V`。サイトの見た目は `npm run dev` で確認できます。

開発中は保存・ファイルの追加・削除が自動反映されます。入力ミスがある場合はターミナルにファイル名と項目が表示されます。
本番公開にはビルドとデプロイが必要です。

詳しい設定は [編集ガイド](../docs/content-guide.md)、掲載した実績の根拠は [出典メモ](../docs/content-sources.md) を参照してください。
